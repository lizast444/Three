---
name: Offline-only product scope
description: The user's standing data-storage requirement for Three Bearings.
---

Three Bearings is a personal, offline-first tool. User-created data must stay on the device; the app must work without internet and must not sync to a server.

**Why:** The user explicitly chose a fully autonomous offline app and a fresh start rather than migrating old server data.

**How to apply:** Keep persistence local in future features. Ask before adding any remote storage, sync, or account-dependent behavior.
